# lb6-7 — тест-опитувальник

Лабораторні роботи №6–7 на Windows Forms (.NET): програма-тест із п'ятьма питаннями.

## Як працює

- Питання завантажуються з файлу `questions.TXT`, варіанти відповідей — з `answer.TXT`.
- Для відповідей використовуються різні елементи керування: випадні списки, списки та списки з прапорцями (кілька варіантів).
- Після натискання «Відповісти» вибрані відповіді зводяться в таблицю, після чого можна перевірити результат.

## Запуск

Відкрийте `lb6+7.sln` у Visual Studio і натисніть F5. Поруч із виконуваним файлом мають лежати `questions.TXT` і `answer.TXT`.
